## About The 2003 Archive:

This is the original version of my <a href="https://zxsa.co.uk/" target="_blank">ZX Spectrum Archive.</a>, preserved exactly as it stood in 2003.

I abandoned the site that year, and for a long time it sat untouched — a little fossil from the early web. My new archive has been completely rebuilt from the ground up, but I thought visitors might enjoy seeing how the project looked in its earliest form. The difference between then and now is… substantial.

The 2003 site was created entirely in Microsoft FrontPage 2000, a web design application so notoriously clumsy that even at the time it was the punchline of many jokes among actual web designers. Its output hasn’t aged gracefully. Modern browsers struggle with the original HTML, so this restored version includes a handful of tiny fixes to make it appear as it would have in Internet Explorer 5/6. I’ve also replaced a couple of missing images, tidied up some formatting, and added a favicon — nothing more.

Most of the external links are long dead, pointing to sites that vanished years ago, but that’s part of the charm. This snapshot offers a small window into how the archive looked when I left it behind in 2003, quirks, broken links and all.
